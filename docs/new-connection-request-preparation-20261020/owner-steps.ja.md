## 実行前に追加で確認する必要がある範囲

1. **申請前の local 状態整理**: 08:27 UTC の保存済み preview では、この client の継続 record が missing、初回 record が expired。現行 begin は未終了 enrollment を無断で置き換えない。新しい requestId でも旧 record が closed でなければ拒否する。正規の明示終了が必要になり得るが、今回は実行しない。既存 cancel は保存済み client があれば忘却も行い得るため、限定した許可なしに実行しない。旧 fcf grant の解除とは区別する。
2. **新規申請だけでも秘密材料を作る**: begin は client 用初回認証 proof を生成し、正規保護 store へ保存してから送信する。server request も初回 claim proof を発行し、private companion が取得・保持する。broker が必要なら ensure が起動し得る。grant 有効化前でも、今回禁止された「資格の作成・取得・保存」に当たるため、別許可が必要。
3. **本人の最終承認**: browser の最終ボタンは server 側の役割別資格発行・保護保存・grant 有効化を伴う。人間の操作であっても、この段階に進める許可を別に確認する。agent は押さない。
4. **受取・接続**: get は初回材料の受取・保存、復元・必要な更新を伴い得る。本人承認が終わっても、今回の「申請準備」から自動実行しない。
