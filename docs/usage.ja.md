# 使い方

[入口へ戻る](../README.md) · [English](usage.en.md)

## ワークスペースとセッション

1. Pi で `/pi-console` を実行し、表示された URL を開きます。標準ポートは `31717` です。使用中なら `/pi-console 31719` のように変更できます。`/pi-console stop` で管理対象サーバーを停止します。サーバーは独立したバックグラウンドプロセスで Pi の終了・再読み込み後も動き続け、`/pi-console status|restart|port` や Pi の外の `scripts\pi-console.ps1 <コマンド>` でも同じサーバーを管理します。
2. **Workspaces** で既存のワークスペースを選ぶか、**Add workspace** の開閉から **Browse folders**（または絶対パス）と **Add & open** で登録します。モバイルでは一覧上部の **Add a workspace** から登録フォームへ移動できます。ワークスペースはサーバー側の作業フォルダーで、独立した「プロジェクト」データはありません。スマートフォンのフォルダーではありません。
3. セッションを選ぶか新規作成し、**Chat** で Pi に指示を送ります。待機中は **Send**、Pi 実行中は同じ操作位置が **Stop** に切り替わります。**Queue after run** はコンソール側の保留キューに入り、Pi へ発送されるまでは入力欄上の一覧で本文の編集・削除ができます（添付はそのまま保持）。**Steer now** は即時に Pi へ送られ、編集・取り消しはできません。キューはサーバー再起動後も保持されますが、**Stop**・発送失敗・未確定の配信があるとキューは一時停止し、**Resume queued**（順番どおりに送信）または **Remove** で明示的に処理するまで送られません。キューに項目があるセッションは、閉じる・ごみ箱への移動の前に Resume または Remove が必要です。キューはセッションごとに最大16件（合計64 MiB）で、Console データディレクトリに永続化されるため再起動しても失われず、**Resume queued** を押すまで送信されません。配信が未確認の保留項目は Pi に届いている可能性があるため、再送前に警告を表示します。セッション内でモデルと思考レベルを選べます。**Context** には Pi が応答後に報告した使用量が表示されます。新規セッションは、最初の指示でファイルが保存されるまではサーバー内だけに存在します。

**Manage workspace** では表示名の変更・固定・登録解除ができます。**Remove from Console** は登録だけを解除し、フォルダーや Pi セッションは残ります。フォルダーブラウザーはサーバー上の現在のフォルダーにサブフォルダーを作れます。**Open on host PC** は登録済みのフォルダーをホスト Windows の画面で開きます。スマートフォンから押しても、スマートフォンのファイルアプリは開きません。

## 会話、添付ファイル、プレビュー

- 入力欄左下の **🎙** で音声入力を開き、言語を選んで **開始**（英語UIは **Start listening**）を押すと、開いている端末のマイクで認識します。最大60秒で停止し、確定した文字を **入力欄へ挿入**（**Insert into prompt**）でカーソル位置に追加します。元の本文・添付は保持し、自動送信はしません。キャンセルやセッション・表示切り替えでは認識を中止します。Web Speech APIには対応ブラウザーとHTTPSまたは安全なローカル接続が必要です。音声はブラウザー提供元へ送信される場合があり、必ず端末内だけで処理されるわけではありません。非対応の場合は端末のキーボード音声入力をご利用ください。Consoleサーバーへの音声アップロード・Whisper接続は行いません。
- キュー一覧は高さを制限して独立にスクロールし、入力欄と **Queue**／**Stop** を押し出しません。PC では Enter で送信、Shift+Enter で改行します。タッチ端末では Enter は改行で、**Send** をタップして送信します。Ctrl+Enter／⌘+Enter も送信に使えます。
- 未送信の本文と添付はワークスペース・セッションごとに分け、このブラウザーの IndexedDB に保存して、切り替え・再読み込み後に復元します。他の端末とは同期せず、自動送信もしません。送信が確認された分だけ消し、送信中に追加した入力は残します。保存に失敗した場合は警告を表示し、未保存の変更がある間はページを離れる際にも確認します。ブラウザーのデータ消去・容量制限などでは保持できない場合があります。共有端末では下書きの本文と添付も端末内に残ることに注意してください。
- 入力欄左下の **📎 Attach** ボタンから、UTF-8 の小さなテキストファイルまたは PNG/JPEG/GIF/WebP 画像を最大4個添付できます。選択したファイルは取り外し可能なチップとして表示されます。Pi の思考とツール実行は会話内に分けて表示され、コマンドの詳細はタップで展開できます。**Instructions** から過去の指示へ移動でき、回答下の **Copy all** で回答をコピーできます。
- 回答は表・リスト・コードブロックを含む Markdown として表示します。生 HTML と外部画像は描画しません。
- 回答中の `.txt`、`.md`、`.markdown` と一般的なソース／設定ファイル（`.ts`、`.py`、`.go`、`.json`、`.yaml` など）、画像（PNG/JPEG/GIF/WebP）、動画（MP4/WebM）は、選択中のワークスペース内にあれば読み取り専用でプレビューできます。本文、Markdown リンク、インラインコードのパスに対応します。ワークスペース内の Markdown 画像もボタンからプレビューできます。ディレクトリー名付きの通常の文章なら、空白を含むパスも検出します。外部画像は自動読み込みしません。
- テキストのプレビューはワークスペース外（シンボリックリンクによる逸脱を含む）、バイナリ、未対応形式、256 KiB を超えるファイルを拒否します。画像は20 MiB、動画は512 MiBまでを許可し、拡張子とファイル署名を検証します。動画はブラウザーが対応するコーデックのみ再生でき、シーク用の範囲取得に対応します。編集機能はありませんが、ブラウザーによるメディアの保存を防ぐ機能ではありません。**Copy** はテキストの元の本文をコピーします。コードには行番号が付き、`src/main.ts:42`、`src/main.ts:42:8`、`src/main.ts#L42` で指定行に移動できます。プレビュー内のリンクを辿った後は **Back** で戻れます。

## 実行状況と Orchestrator

- **Execution** に Pi のツールと確認できたフォアグラウンド pi-subagents、セッションに紐づく Orchestrator の活動が表示されます。紐付けを確認できない項目は **Unattached** 扱いです。承認を行う画面はありません。Pi が提供する場合、実行中のプログラムやコマンドも表示します。
- **Activity** にはサブエージェント、入力待ち、終了結果、最近の問題が表示されます。画面上部の Activity 通知欄は件数を残して折りたため、ヘッダーの通知ボタンから開けます。終了項目はサーバーが保持する間（最大24時間）確認できます。ツールや実行の失敗通知は約7秒で消えますが、通知の **View in Execution** から該当イベントを開けます。詳細は Execution の履歴に残ります。バックグラウンドの **Inspect background result** は拡張機能から取得可能な範囲の結果だけを表示し、失効した結果を復元しません。
- 互換性のある ludi-agent-kit がインストールされている場合、**Execution** から選択中の Pi セッション・ワークスペースに紐づく別の Orchestrator 実行を開始できます。Pi のセッションモデルとは別のモデル設定を使い、プロバイダー料金が発生し得ます。新規セッションには保存のための短い Pi 応答を先に生成し、終了後は短くまとめた結果を Pi に渡して通常の回答として保存します。これらもモデル呼び出しです。進捗は Chat にリアルタイム表示されますが、進捗そのものは会話に保存されません。Chat の kit 報告、Execution の実行カード、新規実行フォームは折りたためます。詳細は Execution の kit 状態から再構成されます。
- Kit 実行中、同じセッションへの Pi 指示は一時停止します。**Execution** に質問が表示されたら選択肢（または自由記述）を送信できます。すべての質問への回答後、kit が自動で再開し、追加のモデル呼び出しが発生する場合があります。再開が失敗し、回答済みの同じ実行が再開可能なままなら、**Retry continuation** で回答を再送せずに再開だけ試せます。再試行もモデル呼び出しが発生し得ます。再開できない間は **Continue Pi chat while kit is paused** を選ぶと、その実行を保留したまま Pi の会話に戻れます。再試行中は再び Pi への指示が一時停止します。回答は kit のリポジトリー単位の判断記録にも残ります。kit は完了したが Pi の会話への最終報告だけが失敗した場合は、Execution の **Retry saving report to Pi** で報告だけを再送できます。この操作は kit を再実行しませんが、Pi のモデル料金が発生する場合があります。最終報告の失敗を解決するまでは、同じセッションで次の kit 実行を始められません。前回の送信結果が不明な場合は、二重投稿を避けるため再送を拒否し、Pi セッションの確認を求めます。送信結果が不明なら Pi の履歴と Execution の報告を確認し、再送せず次に進む場合に限り **Mark report handled after inspection** を選びます。確認ダイアログの承認後、報告は「手動対応済み（Pi への保存は未確認）」となり、再送はできなくなります。同じセッションで次の kit 実行を始められます。報告失敗と送信済みか不明な状態はデータディレクトリーの `report-recovery/` に保存し、サーバー再起動後も復元します。復元後に自動で Pi に再送することはありません。Pi セッションの削除やワークスペースの解除は未解決の報告がある間は拒否します。ブラウザーの添付ファイルと **Stop** は kit 実行には使えず、Pi Console から kit 実行をキャンセルすることはできません。kit の報告を Pi に保存中は誤って中断しないよう **Stop** も無効です。Pi の通常の **Stop** は Console の保留指示を保持して一時停止し、Pi に `abort` を送ります。Pi に送信済みの steering キューは解除します。

## モバイル、通知、設定

スマートフォンでは Workspaces → セッション一覧 → Chat / Execution の順に移動します。アプリ内の戻る操作とブラウザーの戻る／進む操作で一覧へ戻れますが、Pi ワーカーは停止しません。再接続してもワーカーは終了しません。PWA をインストールしてもオフラインでは使えません。

**Settings** では表示形式、外観、Codex 互換のペットなどを設定できます。言語切替は設定とナビゲーションを対象とし、アプリ全体を翻訳するものではありません。ペットは別途導入された `pet.json` とスプライトシートから見つかり、ドラッグで移動できます。**Sessions → Automatic cleanup** は、最終更新から指定日数が経った Pi セッションファイルを Windows のごみ箱へ移動します（標準では無効）。Pi セッションは他アプリと共有されるため注意してください。手動で1件ずつごみ箱へ移すこともできます。

ツールや実行の失敗は画面上部に約7秒の小さな通知として表示され、レイアウトを押し下げません。消えた後の詳細は Execution で確認できます。**Sessions** の完了通知は、タブを開いたまま隠したときのブラウザー通知です。権限を求めるのは有効化したときだけです。終了時刻の予測や、ブラウザーを閉じた後の通知はありません。**Orchestrator settings** では、日本語など自由な表示名で最大16件のモデルを登録・改名・削除できます。計画・調査、コード作業・テスト、レビュー、画像確認、ブラウザー操作への使用許可をチェックボックスで指定し、下の capability 経路で優先・代替モデルを選びます。新規登録は使用許可なしから始まり、許可のない用途には選ばれません。経路と agent の役割の両方の許可が必要です（画像レビューは画像確認＋レビュー、画像を扱う planner/scout は画像確認＋計画・調査）。画像確認にはモデルの画像入力対応（vision 対応）も必要です。これはモデルの使用先の制限で、ツールや OS の権限変更ではありません。能力・費用分類は Kit の経路判断用の申告です。費用不明なら `high` を維持し、`free` / `included` は確認済みの場合だけ指定してください。既存 Kit 割り当ては別の折りたたみ欄に保持し、新しい登録の許可設定の対象外です。登録設定とその経路は Console のデータディレクトリーの `orchestrator-models.json` に保存し、Console から開始・再開したランにのみ適用します（Kit の CLI や Pi の会話モデルには適用しません）。代替モデルの順序は矢印で変更できます。標準 capability の無効化で必要な agent が使えなくなる場合があります。設定の詳細と保存先は [運用・開発ガイド](operations.ja.md)を参照してください。
