# Pi Console 0.5.4

0.5.4 はドキュメント整理と安定性修正のリリースです。**公開・デプロイ・再起動はまだ行っていません。** 以下はパッケージに含める予定の内容です。

## ユーザー向けの主な変更

- **Pi 1.5.0 対応**：対応範囲を安定版 `0.99.2〜1.5.0` に広げました。1.5.0 と 1.4.0 で実 SDK の初期化・拡張連携・履歴取得、1.5.0 では隔離したパッケージ導入・起動・停止をモデル呼び出しなしで確認しています。範囲内の安定版は対応対象ですが、全バージョンを個別実行したわけではありません。プレリリース版と 1.5.0 より新しい版は引き続き対象外です。
- **保留キューの「Discard queued」**：キューが停止中（Stop・送信失敗・配信未確認・再起動後）に、個別の Remove に加えて全項目をまとめて破棄できるようにしました。Pi へ送信中の項目がある間は実行できず、確認ダイアログで「届いている可能性のある項目を削除しても送信済みは取り消せない」ことを説明します。
- **Activity 通知の順序保持**：通知パネルを開いている間は、サーバーが緊急度順に並べ替えてもカードの表示順を固定します。ポーリングで項目が消えた場合、その場所には無効な tombstone が残り、別のカードがポインターの下へ滑り込んで誤クリックを起こさないようにします。パネルを閉じて開き直すと新しい順序になります。
- **Execution のコピー機能**：失敗・中断・ブロック・決定のノードで **Copy context**、失敗系イベントで **Copy log** を選べます。イベントは ID・種類・時刻・状態・ソースに加えて全 payload をそのまま出力し、ノードコピーには関連イベントも含めます。自動コピーに失敗した環境では、テキストを選択して手動コピーできるフォールバックを表示します。

## Dots・ローカル MCP の一時的な提供休止

このリリースでは、Pi Console が提供する Dots 連携と MCP 接続（ローカル再開、フォルダー、Pi control、readonly）を対象外にしています。設定画面の接続項目・接続受付・`local-resume` CLI は利用できず、以前の環境変数や保存設定では再有効化されません。コードと保存設定は削除せず、後続の作業のために保持しています。Pi の通常セッション、Pi 自身の MCP 拡張、Chat、Execution、音声入力、リモート接続は対象外です。`owner-login` は音声設定などの本人確認用として残ります。`docs/dots-*` やローカル MCP の設計・検証資料は過去の開発記録であり、このリリースの有効化手順ではありません。

## パッケージ内容

npm パッケージ内の資料は、`docs/` 直下の Markdown、画面例の画像（`docs/images/`）、リリースノート（`docs/releases/*.md`）に限定します。設計資料の Markdown は履歴として残しますが、検証用アーカイブ・ログ・スクリプト・JSON 証跡などはディスクに保持したまま配布対象から外しました。

## 検証状況

- `npm test`：517 passed / 11 skipped、失敗なし（スキップは環境依存の既存項目）。
- ブラウザー検証は Windows Chrome headless で実施し、機能別の検証にはモック API を使用しています。0.5.4 の PWA キャッシュ切替・オフラインシェルも確認しました。実機 Safari / iOS、Firefox / Edge、実スクリーンリーダー、モデル呼び出しや実運用の外部接続を伴う受入検証は未実施です。
- 本番 URL への適用、公開、デプロイ、サーバー再起動は行っていません。

## リリース手順の注意

作業ツリーには既存の証跡ファイルが多数残っているため、`git add .` は安全ではありません。変更は個別に選択し、コミット・push は別途行ってください。

## 既知の注意

- 以前の Windows スタートアップ版から更新する場合は、npm 更新前に[バックアップと移行](../upgrade-storage.ja.md)を実行してください。
- Remote connections は引き続き本人設定済みの接続でのみ利用できます。本番適用済みとして扱わず、利用環境では接続テストを実施してください。
